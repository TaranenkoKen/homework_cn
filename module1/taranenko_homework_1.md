## Завдання 1. Дослідження мережі

### Виконана команда
```bash
ip a
```

### Результат виконання команди
```text
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
      valid_lft forever preferred_lft forever
    inet 10.255.255.254/32 brd 10.255.255.254 scope global lo
      valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host
      valid_lft forever preferred_lft forever
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether 00:15:5d:d7:aa:6a brd ff:ff:ff:ff:ff:ff
    inet 172.17.168.17/20 brd 172.17.175.255 scope global eth0
      valid_lft forever preferred_lft forever
    inet6 fe80::215:5dff:fed7:aa6a/64 scope link
      valid_lft forever preferred_lft forever
```

### Аналіз підключення:

- Інтерфейс: eth0
- Тип підключення: Ethernet (віртуальний мережевий адаптер WSL)
- MAC-адреса: 00:15:5d:d7:aa:6a
- IP-адреса: 172.17.168.17 (Рівень моделі OSI: Мережевий рівень / L3)
- Маска: /20 (Рівень моделі OSI: Мережевий рівень / L3)
- Gateway (шлюз): 172.17.160.1
- Broadcast (широкомовна адреса): 172.17.175.255
- Hosts (кількість хостів): 4094 хости (оскільки для маски /20 виділяється 12 біт під хости, формула розрахунку: 2^12 - 2)

## Завдання 2. Дослідження маршрутизації

### Виконана команда
```bash
ip r
```

### Результат виконання команди
```text
default via 172.17.160.1 dev eth0 proto kernel onlink
172.17.160.0/20 dev eth0 proto kernel scope link src 172.17.168.17
```

### Аналіз маршрутизації:

- Протокол: kernel (IP-адреса та маршрути були призначені ядром системи)

## Завдання 3. Знаходження публічної IP-адреси

### Виконана команда
```bash
curl ifconfig.io
```

### Результат виконання команди:
```text
5.182.97.83
```

### Порівняння та аналіз локальної і публічної адрес:

- Вони однакові? Ні, вони різні. Моя локальна адреса — 172.17.168.17, а публічна — 5.182.97.83.
- Чому вони різні? Це відбувається через роботу технології NAT (Network Address Translation) на домашньому роутері. Інтернет-провайдер надає роутеру лише одну публічну IP-адресу для виходу в глобальну мережу. Водночас роутер створює власну локальну мережу і видає всім підключеним пристроям приватні IP-адреси. Коли мій комп'ютер звертається до інтернету, роутер автоматично підміняє локальну адресу на публічну, а коли приходить відповідь — перенаправляє її назад на мій пристрій. Це дозволяє економити публічні IPv4-адреси та забезпечує маршрутизацію трафіку в домашній мережі.
